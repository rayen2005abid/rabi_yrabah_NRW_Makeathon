# I. UX Audit

## Current Status

The application already separates factory/operator views from admin and presentation views.

Factory-facing screens include:

- Factory Console
- Receive Box
- Production
- Live Warehouse
- History
- Faults

Advanced controls live in Admin Panel and Robot/technical views.

## Required Preservation

The operator must only request:

- core type
- quantity

The operator must not choose:

- box ID
- FIFO order
- physical storage slot
- robot route
- manual robot action

## Presentation Mode

Demo Showcase already exists and should be expanded into a clear 5-7 minute scoring flow. It should expose one-click scenarios and a visible checklist for image receipt, classification, quantity, registration, timestamp, drying timer, slot choice, robot task, path, and Digital Twin update.
